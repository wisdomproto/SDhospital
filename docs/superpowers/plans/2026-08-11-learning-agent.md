# 쌓일수록 똑똑해지는 채팅 — 설계

`2026-08-03-owner-chat.md` 가 **무엇을 답할지**를 정했다면, 이 문서는 **시간이 갈수록 어떻게 나아지는지**를 정한다.
앞 문서의 규칙(문 일곱 개·지켜야 할 선·경미 회송)은 전부 그대로 유효하고, 여기서 뒤집지 않는다.

## 오늘 바뀐 전제 (2026-08-11)

| | 전 | 후 |
|---|---|---|
| 비용 | 회당 100원을 넘기지 않는다 | **제약 아님.** 소비자 만족이 우선 (원장 결정) |
| 재료 | 슈슈 시연 데이터뿐 | **10년치 진료 기록 + 카톡 상담** 이 있다 |
| 모델 | Claude 고정 | **자체 서버 오픈 모델**(Gemma 4 급) 로 갈 계획 |
| 대화 | 새로고침하면 사라짐 | **전량 보관**(`chat_message`) — 오늘부터 쌓인다 |

## 지금 구조는 시간이 갈수록 **덜** 똑똑해졌다

처음 만들 때 비용을 고정하려고 회차 15건·다이어리 30일·검진 2건에서 잘랐다.
그러면 **기록이 쌓일수록 잘려 나가는 비율이 커진다.** 3년 뒤 회차가 80건이면 5분의 4를 못 본다.
"쌓일수록 똑똑해진다"의 정반대다. 상한은 오늘 전부 풀었다(슈슈 기준 12,287 토큰).

⚠️ **그런데 상한을 푼 건 시간을 번 것이지 푼 게 아니다.** 10년치·여러 병원으로 가면
통째로 넣는 방식은 반드시 깨진다. 아래 설계는 그 지점을 전제로 한다.

## 쌓이는 것은 **세 층**이고, 층마다 속도와 주인이 다르다

```
3층  병원의 답변 자산      모든 대화가 기여 · 모든 환자가 쓴다      ← 진짜 해자
2층  그 집의 카드          그 집의 대화가 기여 · 그 집만 쓴다
1층  그 아이의 기록        진료·입원·검진·다이어리                  ← 이미 있다
```

**1층은 EMR 만 있으면 남도 만든다. 3층은 10년치 상담이 있어야 만든다.**
차별화가 어디 있는지가 이 그림에 그대로 나온다.

### 1층 — 그 아이의 기록 ✅ 되어 있다

진료 회차(원문·처방·코멘트) · 입원 이력과 발송된 일일 리포트 · 발송된 검진 · 다이어리 1년 · 먹이는 것.
⚠️ 바이털 수치는 읽지 않는다(38.4는 안심을 주지 못한다). 의료영상은 넣지 않는다(승인 절차 우회 금지).

### 2층 — 그 집의 카드

대화에서만 나오고 **EMR 에는 영원히 안 들어가는 것**을 한 장으로 유지한다.
진료 기록은 "무슨 병이었나"를, 대화는 **"이 집이 어떤 집인가"** 를 남긴다.

```
슈슈 카드
- 보호자: 사진 요청에 3/3 응답. 문의 11건 중 8건이 밤 9시 이후.
- 슈슈: 이동장 스트레스 심함 (2026-05-30 대화)
- 패턴: 2025·2026 두 해 모두 7~8월 식욕 저하
- 지난 판단: 2026-05 1차로 회송 → 3일 뒤 우리로 내원
```

⚠️ **카드는 추론을 사실로 굳힌다.** "이 보호자는 과민반응한다" 가 한 번 적히면 채팅이 그걸
계속 사실로 읽고, 그 집만 조용히 낮게 분류된다. **이 기능의 유일한 사고 경로가 여기다.**
그래서 층을 나눈다 — 검진에서 참고범위가 없으면 판정하지 않고(`unknown`),
생활기록이 적으면 추세를 말하지 않는(`enough=false`) 것과 같은 규칙이다.

| 층 | 무엇 | 조건 | 누가 |
|---|---|---|---|
| **사실** | "2026-05-30 흉수 배액, 이후 재방문 없음" · "사진 요청에 3/3 응답" | 근거 1건 | 자동 |
| **반복** | "두 해 모두 7~8월 식욕 저하" · "문의 8/11건이 밤 9시 이후" | **2회 이상** + 근거 날짜 필수 | 자동 |
| **해석** | "보호자가 걱정이 많다" · "지난 회송 판단이 틀렸다" | — | **사람이 승인** |

**사실·반복은 세는 것**이라 틀려도 근거 날짜로 되짚는다. **해석은 판단**이라 되짚을 방법이 없다.
직원 화면에 제안으로 띄우고 체크해야 카드에 들어간다 — 리포트를 자동 발송하지 않는 것과 같은 자리다.

⚠️ **줄마다 유효기간을 둔다.** 6개월간 새 근거가 없으면 자동으로 내려간다.
안 그러면 2년 전 "이동장 스트레스"를 이미 괜찮아진 아이한테 계속 말한다.
병원 소식에 기간 만료를 넣은 것과 같은 이유 — **내리는 걸 사람이 기억해야 하는 구조는 반드시 실패한다.**

갱신은 **대화가 끝날 때 한 번**, 싼 모델로. 매 메시지마다 돌리면 카드가 출렁인다.

### 3층 — 병원의 답변 자산

10년치에서 뽑는다. **모든 대화가 기여하고 모든 환자가 쓴다.** 셋으로 쓴다.

1. **승인 답변** — 원장이 승인한 문장 목록. 원래 설계("AI 는 고르기만 하고 만들지 않는다")의 재료다.
   기획서 부록의 32건은 **105채널 표본**에서 나온 것이고, 전량이면 훨씬 두꺼워진다.
2. **유사 사례** — "과거에 이런 문의가 이렇게 됐다"를 검색해 프롬프트에 넣는다.
3. **평가 세트** — 프롬프트나 모델을 바꿀 때마다 회귀 검사.

## 불변식 — **저장은 무한, 컨텍스트는 고정**

세 층을 다 넣으면 10년 뒤 프롬프트가 수십만 토큰이 된다. 비용 이전에 **답이 나빠진다** —
10년치 잡담 속에 정작 중요한 한 줄이 묻힌다. 그래서 규칙은 하나다.

```
DB              →  전부 쌓는다 (증빙 + 재료)
컨텍스트         →  크기가 고정이다
  1층  그 아이 기록      … 커지면 검색으로 전환
  2층  카드 1장          … 항상 한 장
  3층  유사 사례 3~5건   … 항상 몇 건
```

**1층이 컨텍스트를 넘칠 때가 에이전트(도구) 착수 시점**이다. 통째로 넣는 대신 찾아 읽는다.

```
search_visits("수술")     오래된 회차를 찾는다
read_visit(id)            그 회차만 꺼낸다
trend("체중", 3년)         추이를 뽑는다
read_card / update_card   카드를 읽고 갱신한다
similar_cases(문의)        3층에서 비슷한 과거 사례를 찾는다
```

기록이 3년치든 10년치든 **읽는 양은 그대로**다. `actions.ts` 한 곳이고 SDK 에 도구 루프가 있다 —
큰 재작업이 아니다. **그래서 지금 서두를 이유도 없다.**

## 10년치를 정답지로 만든다 — **연결 키를 확인했다**

```
카톡 105채널  →  전부 차트번호 보유 (690~11108 · 중복 0)
EMR patient   →  chart_no 컬럼 존재
```

카톡 파일명과 메시지의 `USER` 필드가 차트번호다. 그러면 이렇게 붙는다.

```
카톡:  6195 · 2025-10-05 03:12 · "매일 새벽 발작을 합니다"
              ↓ chart_no + 시각
EMR:   6195 · 2025-10-05 내원 · 입원 · 항경련제
              ↓
라벨:  「지금 와야 했다」 = 예
```

⚠️ **자동 라벨에는 계통 오차가 있다.** "그 뒤에 왔나"로 매기면 **안 왔는데 실제로 응급이었던 건**이
「응급 아님」으로 들어간다. 그런데 그게 정확히 우리가 막으려는 사례다. 그대로 학습시키면 **놓치는 걸 학습한다.**

→ **자동 라벨로 전량 초안 → 원장은 「안 왔는데 위험해 보이는 문장」만 검토.**
전량 라벨링은 못 하지만 저 한 갈래만 보면 된다. 실제로 오늘 읽은 고위험 70건에서
폐수종 의심·수술부위 부기 증대·발 진물·퇴원 후 무배변이 **답 없이 끝나 있었다** — 그게 검토 대상이다.

## 학습(파인튜닝)은 어디에 쓰나

⚠️ **기록을 외우게 하는 데는 쓰지 않는다.** 체중은 어제와 오늘이 다르고, 무엇보다
**다른 아이 정보가 섞여 나온다.** 보호자에게 남의 아이 얘기가 한 번 나가면 그날로 끝이다.
사실은 컨텍스트가 담당한다.

⚠️ **카톡을 그대로 학습시키지 않는다.** 그 데이터의 44%가 봇이고, 사람이 답한 것의 44%가
"주치의 확인 후 답변드리겠습니다"다. 그대로 배우면 **우리가 바꾸려던 그것을 아주 잘하는 모델**이 된다.

**쓰는 자리는 하나다** — 라벨된 (문의 → 실제 결과) 쌍으로 **분류를 학습**시키는 것.
이건 사실 암기가 아니라 패턴이라 다른 환자에게도 전이된다.

다만 **첫 수단은 아니다.** 같은 데이터를 **유사 사례로 검색해 프롬프트에 넣는 것**이 먼저다.

| | 파인튜닝 | 유사 사례 검색 |
|---|---|---|
| 착수 | 데이터 정제 후 학습 | 바로 |
| 틀린 사례 수정 | 재학습 | 그 자리에서 |
| 왜 그렇게 판단했나 | 알 수 없다 | 근거가 답변에 남는다 |

**파인튜닝이 진짜 이기는 지점은 따로 있다** — 오픈 모델이 프롬프트만으로 우리 규칙을 못 따를 때.
그게 자체 구축의 진짜 근거다.

⚠️ 어느 길이든 **라벨된 데이터셋이 먼저**다. 파인튜닝·유사 사례·모델 비교가 전부 같은 재료를 쓴다.
지금 만들어 두면 나중에 무엇을 고르든 낭비가 없다.

## 자체 서버 모델 — 재고 나서 정한다

Gemma 4 사양은 걸림돌이 아니다. 12B·26B A4B·31B 이 **256K 컨텍스트**(우리는 12K)이고
**이미지·영상·음성을 받는다.** 마지막 게 크다 — 수술부위 문의 39건의 태반이 사진 기반인데
지금 채팅은 텍스트만 받는다. **오픈 모델로 가는 게 기능을 늘리는 방향**이 된다.

남는 건 스펙으로 알 수 없는 항목 둘 — **지시 준수**와 **한국어**.
오늘 하루에만 프롬프트를 네 번 고쳤고(입원 중 오답 · 예약 들이밀기 · 24시간 문구 · 브리핑 오분류)
전부 "지시를 정확히 따르는가"였다. 이 제품의 실패 모드가 **응급을 놓치는 것** 하나라 그게 전부다.

**그래서 순서는 이렇다.**
1. Claude 로 품질 기준선을 만든다 (기준선 없이 갈아타면 무엇을 잃었는지 못 본다)
2. 평가 세트로 두 모델의 **응급 놓친 건수**를 잰다
3. 그때 정한다

현실적인 결론은 「전부 자체」가 아니라 **역할 분리**일 가능성이 높다 —
보호자에게 나가는 답은 큰 모델, 카드 갱신·요약·분류·인덱싱은 자체 서버. 양으로는 대부분이 아래쪽이다.

⚠️ **4비트 양자화로 가지 않는다.** 제일 먼저 망가지는 게 지시 준수이고, 그게 우리가 유일하게 못 잃는 능력이다.
26B A4B 를 8비트로 쓰려면 **VRAM 48GB 이상**이 필요하다(가중치 28.8GB + KV 캐시).
⚠️ **카드를 먼저 사고 모델을 맞추지 않는다.** 클라우드로 하루 재보고 산다.

## 만드는 순서

| | 무엇 | 착수 신호 | 상태 |
|---|---|---|---|
| 0 | 대화 보관 | — | ✅ 2026-08-11 |
| 1 | **지난 대화를 컨텍스트에 넣기** | 대화가 쌓이기 시작 | 다음 |
| 2 | **정답지** (카톡×EMR 조인 → 자동 라벨 → 원장 검토) | 10년치 EMR 확보 | 막힘 ⬜ |
| 3 | 평가 세트 · 모델 비교 | 2 완료 | |
| 4 | 유사 사례 검색 (3층) | 2 완료 | |
| 5 | 카드 (2층) | 대화 표본이 모임 | |
| 6 | 에이전트(도구) | 1층이 컨텍스트를 넘침 | |
| 7 | 파인튜닝 | 4로 부족하고 오픈 모델이 규칙을 못 따를 때 | |

**1번이 가장 싸고 가장 먼저 티가 난다** — 오늘부터 대화가 쌓이니 다음 질문에
"지난주에 물어보셨던 그거"가 된다. 코드 열 줄이고 카드보다 먼저 된다.

**2번이 전부의 병목이다.** 3·4·5·7이 전부 여기 재료를 쓴다.

## 지켜야 할 선 (승계 + 새로 생기는 것)

기존 규칙은 그대로다 — 진단하지 않는다 · 안심시키지 않는다 · 약을 지시하지 않는다 ·
진료 원문을 옮기지 않는다 · 우리가 수술한 부위는 경미로 안 내린다 · 다른 병원을 언급하지 않는다.

새로 생기는 것:
- ⚠️ **카드의 「해석」층은 사람이 승인한다.** 자동으로 들어가면 그 집이 조용히 낮게 분류된다.
- ⚠️ **카드 줄에는 근거 날짜가 붙는다.** 없으면 되짚을 수 없다.
- ⚠️ **유사 사례를 보호자에게 옮기지 않는다.** 남의 아이 얘기다. 판단에만 쓴다.
- ⚠️ **대화 로그는 지우지 않는다.** 보호자가 지울 수 있으면 증빙이 무너진다. 화면에서 감출 뿐이다.
- ⚠️ **모델을 감으로 바꾸지 않는다.** 응급 놓친 건수로만 정한다.

## 하지 않는 것

- **기록을 외우게 하는 파인튜닝** — 다른 아이 정보가 섞여 나온다
- **카톡 원본을 그대로 학습** — 44%가 "확인 후 답변드리겠습니다"다
- **자동 이상 감지·먼저 말 걸기** — "지켜보고 있다"는 인상이 곧 책임이 된다(앞 문서 그대로)
- **카드를 자유 서술로 두기** — 몇 달이면 소설이 되고 채팅이 그 소설을 사실로 읽는다
- **컨텍스트를 무한히 늘리기** — 비용 이전에 답이 나빠진다
