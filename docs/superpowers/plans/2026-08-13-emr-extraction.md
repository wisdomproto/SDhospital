## 이어받는 법

작업 목록은 `D:/sd hospital/_추출/_작업목록.json` 에 있고 `done` 플래그가 갱신돼 있다.
장수 적은 순으로 정렬돼 있으니 위에서부터 하면 된다.

```bash
node scripts/load-emr.mjs "D:/sd hospital/_추출"        # 환자·회차·입원·카톡
node scripts/load-cautions.mjs "D:/sd hospital/_추출"   # _pending ⚠️ → patient_caution
```

한 명 추출하는 순서:
1. `<원본>/<폴더>/진료기록/*.jpg` 를 **전부 읽는다** (한 명당 8~17장)
2. `D:/sd hospital/_추출/<차트번호>/환자.json` 을 쓴다
3. 위 두 스크립트를 돌린다

`환자.json` 규칙:
- `note` 는 **원문 그대로** 옮긴다 — 진료기록이 표준화돼 있지 않아 요약하면 정보가 사라진다
- 매일 반복되는 청구 항목(입원-일반·수액·정맥카테터·인퓨전펌프·처치-입원·정맥주사)은 **뺀다**
- `deceased: true` + `deceased_note` — 사망이 기록에 **명시된** 경우만
- `_pending` 의 `⚠️` 항목이 곧 `patient_caution` 이 된다

1. **`patient_caution` 을 컨텍스트에 연결** — 프롬프트에 106개 특례를 쓰지 않는다.

   ⚠️ 단 이 표에는 보호자에게 보이면 안 되는 문장이 섞여 있다(비용 상담, 1차 병원과의

   「내원하세요」를 기본값으로 놓지 않기
3. **`confirm` 17건을 원장님이 실제로 확인** — 채팅을 열기 전 관문
