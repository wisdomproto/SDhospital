# 보호자 채팅 — 증상 상담

원장님이 넘겨준 **채널 대화 백업 105건**(전체 1만여 건 중 샘플)을 전수 분석했다.
카카오 채널 상담 원본이고 `DATE · USER · MESSAGE` 세 칸이다. USER 가 숫자면 보호자(차트번호), 아니면 병원이다.

⚠️ **원본은 저장소에 넣지 않는다.** 보호자 이름·전화번호가 평문으로 들어 있다. 집계와 결론만 남긴다.

## 범위 (2026-08-03 확정)

- **예약 → 전화 상담으로 연결한다.** 자동으로 잡지 않는다.
- **검사 결과·식사·배변·입원 경과 → 리포트로 갈음한다.** 채팅이 답할 일이 아니다.
- **남는 것은 증상 상담뿐이다.** 이 문서는 그것만 다룬다.

### 병원이 이미 자동응답을 쓰고 있고, 그 내용이 "증상 상담은 안 합니다" 다

| 자동응답 | 횟수 |

**병원이 하는 말의 44%가 봇이고, 그 절반이 "여기서는 증상 상담 안 합니다" 다.**
그런데 보호자는 계속 증상을 적어 보낸다 — 194건. 채널을 막아도 물어볼 데가 여기뿐이기 때문이다.

**우리가 만들 자동답변은 새로운 시도가 아니라, 이미 있는 "안 해드립니다"를 쓸모 있는 것으로 바꾸는 일이다.**

새벽 2시에 아이가 토했는데 받는 답이 그것이다.

## 설계

### 자동답변이 해야 하는 일

데이터가 말하는 답은 세 갈래뿐이다 — **지금 오세요 / 아침에 오세요 / 이렇게 해보세요**.
원격으로 끝나는 3%를 늘리려 하면 안 된다. 그건 진료다.

```
증상 메시지
  │
  ├ ① 지금 와야 하는 것        발작·경련 / 호흡곤란 / 배뇨 못 함 / 다량 출혈 /
  │                            수술 부위 벌어짐·출혈 / 의식 저하
  │                            → "지금 오세요" + 야간 안내 + 전화 연결
  │
  ├ ② 아침에 와야 하는 것      3일 이상 안 먹음 / 반복 구토 / 혈변 / 절뚝임 지속
  │                            → "내일 오전 예약 잡아드릴게요" + 그때까지 볼 것
  │
  └ ③ 물어볼 것부터 채우는 것  피부 붉어짐 · 실밥 부위 · 눈곱 …
                               → 사진 요청 + 언제부터·횟수·먹는 약 물어보고
                                 **주치의에게 넘긴다**(사람이 답한다)
```

**①만이라도 밤에 즉시 나가면 지금보다 낫다.** 지금은 그 자리에 "안 합니다"가 나간다.

### 지켜야 할 선

- **진단하지 않는다.** 병명을 말하지 않는다. `~일 수 있습니다` 도 하지 않는다.
- **안심시키지 않는다.** "괜찮아요"는 사람만 한다 — 실제로도 10%뿐이고 그마저 주치의 확인을 거친다.
- **약을 지시하지 않는다.** 중단·투여 모두. 실제 조치 지시 13%는 넥카라·급여 중단 같은 것이고 주치의 판단이었다.
- **①은 넓게 잡는다.** 놓치는 쪽이 과하게 부르는 쪽보다 훨씬 나쁘다.
- 답변 끝에는 항상 **"의료진 확인 전 자동 안내"** 라고 밝힌다.

### 사람에게 넘길 때

③으로 분류된 건 **직원 화면의 "오늘 할 일"에 올린다.** 지금 리포트가 그러는 것과 같다.
답장 초안은 AI 가 만들되 **발송은 사람이 누를 때만** — 입원 리포트의 `ready_at`/`sent_at` 과 같은 구조다.
이러면 44%의 "주치의 확인 후" 왕복이 한 번으로 줄고, 물어볼 것(사진·시점·횟수)은 이미 채워져 있다.

## 만드는 순서

| | 무엇 | 왜 |
|---|---|---|
| **C-1** | **응급 분류(①) + 야간 즉시 안내** | 지금 "안 합니다"가 나가는 자리. 규칙만으로 된다 |
| **C-2** | **문진 채우기(③)** — 사진·시점·횟수·복용 약 | 왕복 44%를 한 번으로 줄인다 |
| **C-3** | **직원 화면 인계 + 답장 초안** | 발송은 사람. 기존 구조 재사용 |
| **C-4** | **수술 부위 전용 흐름** | 문의 4위(29건)인데 답이 정형적이다 — 사진 + 며칠째 + 벌어짐 여부 |
| **C-5** | 예약 요청은 **전화 연결**로 | 자동으로 안 잡는다 |

C-1·C-2 는 **모델이 필요 없다.** 증상 키워드와 규칙이다.
모델은 C-3 초안에서 처음 필요하고, 그때도 보호자가 아니라 **직원에게** 말한다.

  전체에서 **응급으로 판명난 사례**를 뽑아야 "지금 오세요" 기준을 사람 손으로 정할 수 있다.
- **비식별화가 먼저다.** 이름·전화번호가 평문이다.
- 야간 응급 안내 문구와 ① 목록은 **원장님이 직접 확정해야 한다.** 우리가 정할 것이 아니다.
